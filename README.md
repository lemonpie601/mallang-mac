# Marinara Desktop

마리나라를 데스크톱 운영체제처럼 바꿔 주는 확장이에요. 켜는 순간 다른 앱을 연 것처럼 보이게 하는 게 목표예요. 컴퓨터에서는 데스크톱처럼, 휴대폰과 태블릿에서는 홈 화면처럼 보여요.

## 컴퓨터에서

- **홈 = 바탕화면 위젯 보드**: 홈에서는 창이 사라지고 배경화면 위에 위젯만 남아요.
  - 왼쪽: 마리나라 홈 위젯(최근 채팅, 교수님 등)
  - 가운데: API 가계부·크레딧 카드를 크기가 섞인 위젯 격자로 보여 줘요. 가계부는 큰 위젯(2×2), 크레딧은 작은 정사각형 위젯이에요. 네 번째마다 하나는 중간(2×1) 위젯이라 자세한 줄이 더 보여요.
  - 오른쪽: **새 채팅** 위젯(대화·롤플레이·게임 앱 아이콘)과 시계, 캘린더, 디데이. 새 채팅도 다른 위젯처럼 옮기고, 크기를 바꾸고, 지울 수 있어요.
  - 모든 위젯이 같은 디자인을 써요. 유리 카드, 22px 둥근 모서리, 작은 회색 제목, 굵은 숫자, 강조색 막대가 똑같아요. 버튼은 마우스를 올렸을 때만 보여요.
- **도움말 문구 → ⓘ**: "캐릭터를 폴더로 드래그 앤 드롭하고…" 같은 긴 안내는 새 폴더 버튼 끝의 ⓘ 아이콘으로 줄어들어요. 마우스를 올리거나 누르면 보여요.
- **메뉴 막대** (위쪽): 로고 메뉴, 앞에 있는 창 이름, 보기·윈도우·Dock·도움말 메뉴, 검색, 제어 센터, 시계가 있어요.
- **Dock** (아래쪽):
  - 평소엔 숨어 있다가 마우스를 화면 아래 끝에 가져가면 올라와요.
  - 마우스를 올리면 아이콘이 커지고, 열린 앱 아래에 점이 생겨요.
  - 가운데에 **최근 채팅 3개**가 캐릭터 얼굴로 나와요. 누르면 바로 열려요.
  - 아이콘을 오른쪽 클릭하면 열기·닫기·아이콘 편집 메뉴가 나와요.
- **창**: 채팅 목록, 채팅/편집 화면, 오른쪽 패널이 각각 떠 있는 창이에요.
  - 빨강을 누르면 홈으로 가요. 노랑은 최소화, 초록은 확대/축소예요.
  - 제목 표시줄을 끌면 옮겨지고, 가장자리를 끌면 크기가 바뀌어요. 더블클릭하면 확대돼요.
  - 화면 맨 위로 끌면 꽉 채워지고, 왼쪽·오른쪽 끝으로 끌면 반쪽에 붙어요.
  - 설정은 넓은 두 칸 창(왼쪽 카테고리, 오른쪽 내용)으로 열려요. 창 크기는 패널마다 따로 기억해요.
- **런치패드**: 모든 앱을 격자로 보여 줘요. 마리나라 홈 탭(교수님, Noodle, Slurp 같은 것)도 각각 앱으로 들어 있어요. 바로 타이핑해서 찾을 수 있어요.
- **바탕화면 오른쪽 클릭**: 위젯 편집, 배경화면, 꾸미기, 데스크톱 보기, 창 정리 메뉴가 나와요.

## 휴대폰·태블릿에서

- **홈 화면**: 위젯과 앱 아이콘 격자가 배경화면 위에 놓여요. 아래에는 마리나라 인사말과 홈 카드가 이어져요.
- **Dock**: 홈 화면 아래에 채팅·캐릭터·페르소나·설정이 떠 있어요.
- **앱**: 큰 제목이 달린 휴대폰 앱처럼 열려요. 태블릿에서는 홈 화면 위에 둥근 카드 창으로 떠요.
- **홈 인디케이터**: 앱 안에서는 아래쪽 가운데 막대를 누르거나 위로 쓸어 올리면 홈으로 돌아가요.
- **위젯 편집**: 홈 화면 빈 곳을 길게 누르면 위젯 편집 모드가 돼요.

## 채팅 화면

- **대화 모드 = 메시지 앱**:
  - 내 메시지는 오른쪽 강조색 말풍선이에요. 상대 답장은 문단마다 따로 회색 말풍선으로 나와요.
  - 작은 동그란 프로필, 가운데 정렬된 상단 이름 바, 조용한 날짜 구분선이 있어요.
  - 메시지 도구는 마우스를 올렸을 때만 보여요.
- **롤플 모드 = 전자책**:
  - 배경 이미지는 빠지고 종이(또는 밤) 바탕에 명조 글꼴로 넓게 읽혀요.
  - 이름은 작은 대문자로 표시돼요.
  - 내 차례는 형광펜 친 구절처럼 보여요.
- 둘 다 제어 센터의 **모양**에서 바꿀 수 있어요. 대화는 "메시지 앱 / 마리나라 기본", 롤플은 "책 (종이) / 책 (밤) / 깔끔하게"예요.

## 꾸미기

- **위젯**: 새 채팅, 시계, 아날로그 시계, 캘린더, 인사말, 디데이, 메모, 사진 위젯이 있어요.
  - 크기: 작게 / 보통 / 크게
  - 스타일: 유리 / 밝게 / 어둡게 / 강조색 / 투명 (메모는 메모 색)
  - 디데이에는 제목과 날짜를 넣어요. 최애 생일이나 기념일을 세어 줘요.
  - 위젯 편집 모드에서는 위젯이 흔들려요. − 를 누르면 지우고, i 를 누르면 설정하고, 끌어서 옮겨요. 아래 막대의 "+ 위젯 추가"로 새 위젯을 넣어요.
- **아이콘**:
  - 앱마다 이름, 두 가지 색, 직접 고른 이미지를 바꿀 수 있어요. Dock 아이콘 오른쪽 클릭 → 아이콘 편집으로 바꾸거나, 제어 센터 → 꾸미기 → 아이콘 편집에서 바꿔요.
  - 전체 아이콘 스타일: 그라데이션 / 유리 / 파스텔 / 틴트 / 다크
  - 아이콘 모양: 둥근 사각 / 동그라미 / 각진 사각
- **강조 색상** 9가지와 **배경화면** 6가지가 있어요. 내 이미지를 올리거나 https 이미지 주소를 넣을 수도 있어요.

## 성능

- 창을 끌어 옮기는 동안에는 블러를 끄고, 화면을 다시 그리지 않는 방식(`translate`)으로 옮겨서 부드러워요.
- 답장이 스트리밍되는 동안 채팅 화면이 바뀌어도 확장은 무시해요. 확인 작업은 1초에 최대 10번만 해요.
- 블러는 채팅 목록 창 한 곳에만 남겼어요.
- 그래도 버벅이면 제어 센터 → 성능에서 **투명 효과 줄이기**와 **움직임 줄이기**를 켜 보세요.
- 이미지는 따로 저장해서, 창을 옮길 때마다 큰 데이터를 다시 보내지 않아요.
- 참고: 마리나라에 다른 확장이 많이 켜져 있으면(특히 `fetch`를 감싸는 확장들) 그쪽에서도 느려질 수 있어요.

## 설치

1. 서버의 `.env`에 `ENABLE_EXTERNAL_EXTENSIONS=true`가 있어야 해요. (지금 설치본에는 이미 켜져 있어요.)
2. **설정 → 고급 → Danger Zone**에서 **Allow third-party extension imports**를 켜요.
3. **설정 → 애드온 → External Extensions**에서 **Import Extension Folder**를 누르고 이 `marinara-desktop` 폴더를 골라요. 폴더 대신 ZIP으로 묶어서 **Import Extension File**로 가져와도 돼요.
4. 가져온 확장을 열고 **Review and Run**을 눌러요. 화면 전체를 바꾸기 때문에 **Full page access** 권한을 요청해요. 확인 창에서 해시와 권한을 확인하고 승인해요.

코드를 고친 뒤 다시 가져오면 확장이 꺼지고 다시 승인해야 해요. 마리나라의 안전장치라서 정상이에요.

## 단축키

| 키 | 동작 |
| --- | --- |
| Ctrl + Alt + D | 데스크톱 ↔ 원래 레이아웃 |
| Ctrl + Alt + L | 런치패드 |
| Ctrl + Alt + H | 데스크톱 보기 |
| Ctrl + Alt + M | 앞에 있는 창 최소화 |
| Ctrl + ` | 다음 창으로 |
| Ctrl + K | 검색 |
| Esc | 메뉴·런치패드·제어 센터·위젯 편집 닫기 |

## 알아 둘 점

- 원래 화면이 필요하면 Ctrl + Alt + D를 누르거나 런치패드에서 **클래식 레이아웃**을 골라요. 오른쪽 아래 **데스크톱 모드** 버튼으로 돌아와요.
- 확장 저장 공간은 1MB예요. 배경화면·사진·아이콘 이미지는 자동으로 줄여서 저장하고, 가득 차면 알려 줘요.
- 밝은/어두운 모드는 마리나라 테마 설정을 따라가요.
- 확장을 끄면 추가한 요소, 스타일, 변수가 전부 사라져요.
- 마리나라 화면 구조(`data-component`, `data-tour` 속성)와 크레딧 확장의 `#mac-credit-home`을 기준으로 동작해요. 마리나라나 그 확장이 업데이트되면 일부가 어긋날 수 있어요.
- 다른 스타일 확장이나 테마 CSS와 같이 켜면 서로 덮어쓸 수 있어요.

## 파일

| 파일 | 내용 |
| --- | --- |
| `manifest.json` | 확장 정보와 권한 (`full_page_access`) |
| `desktop.js` | 창 관리자, 메뉴 막대, Dock, 런치패드, 제어 센터, 위젯·아이콘 꾸미기, 휴대폰 홈 화면 |
| `desktop.css` | 배경화면, 창 틀, 메뉴 막대, Dock, 아이콘 스타일, 팝업, 성능 옵션 |
| `theme.css` | 창 안쪽 색과 컨트롤 모양, 롤플 배경 제거 |
| `layout.css` | 창 안쪽 배치: 채팅 목록 툴바, 두 칸 설정, 캐릭터 아이콘 격자 |
| `home.css` | 홈 = 바탕화면, 유리 위젯, 내 위젯과 편집 모드 |
| `apps.css` | 메시지 앱 같은 대화 화면, 전자책 같은 롤플 화면 |
| `touch.css` | 휴대폰·태블릿 홈 화면, Dock, 홈 인디케이터, 앱 시트 |
